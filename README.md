# 정구(소프트테니스) 경기 대진표 생성기

정구(소프트테니스) 대회의 참가자·팀 정보를 입력하면 조별 리그와 토너먼트 대진표를 만들어 주는 단일 HTML 웹앱입니다. 빌드 없이 브라우저에서 바로 실행됩니다.

- 실행: https://aqss193-pixel.github.io/soft-tennis-bracket/
- 파일: `index.html` (Tailwind CSS CDN, Google Fonts)

## 기능

- 참가자/팀 등록과 시드 지정
- 조별 리그 편성 및 순위표
- 토너먼트 대진표 자동 생성
- 경기 결과 입력에 따른 다음 라운드 자동 갱신
- 대진표 인쇄 및 이미지 저장
